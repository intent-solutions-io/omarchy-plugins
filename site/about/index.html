About Intent Solutions Omarchy Plugins

Intent Solutions Omarchy Plugins is a public catalog that publishes inspectable Omarchy desktop plugins, marketplace listings, source, and shipping status for Omarchy users, plugin maintainers, and people evaluating desktop workflow tools built in public.

The catalog shows what exists, where it comes from, and whether the official marketplace recognizes it. It does not host plugin code or replace the marketplace.

What Intent Solutions Omarchy Plugins does

Publishes the plugin catalog

The catalog gives each Intent Solutions Omarchy plugin a permanent page with its purpose, lifecycle, preview, source, and official marketplace link. Users can compare tools and reach the authoritative install record without guessing which repository is current.

Connects listings to source

Every plugin record is reconciled with a public repository, manifest identity, and marketplace entry. That traceability lets users and maintainers inspect the implementation and verify that the public presentation matches the shipped artifact.

Publishes shipping status

The delivery ledger reports listing, preview, and manifest states from the same catalog pipeline used to build the site. Unfinished or unavailable work stays labeled instead of being presented as complete.

Supports maintainers and related products

The shared widget template gives contributors a tested starting chassis, and the maintainer path turns bounded contributions into ownership opportunities. The site also presents related Intent Solutions desktop products when their status and boundaries can be stated honestly.

What makes Intent Solutions Omarchy Plugins different

16 listings, one canonical inventory

The current public catalog contains 16 officially listed plugins generated from one validated inventory. The README, site data, no-JavaScript index, and individual plugin pages are checked for agreement before release.

Source before claims

Each plugin page links to public source and records repository facts instead of relying on a marketing description alone. A claim can be followed back to the repository and official listing that support it.

Marketplace status is reconciled

The catalog pipeline checks the official Omarchy marketplace rather than treating a hand-written badge as proof. The marketplace remains the authority for listing and installation status.

Previews and manifests are checked together

Repository preview availability, manifest identity, and lifecycle state are captured during the same refresh. That makes visual inspection part of the evidence trail and exposes drift instead of hiding it.

Unfinished work remains visible

Projects in research, review, or development keep those labels until their gates pass. The catalog separates a working public artifact from a future product promise.

Frequently asked questions

What is Intent Solutions Omarchy Plugins, exactly?

It is the public catalog for Intent Solutions Omarchy desktop work. It connects each plugin to its source, official marketplace record, preview, and current shipping state.

Who is the catalog for?

It is for Omarchy users, plugin maintainers, and evaluators who want to inspect a desktop tool before installing it. It is not a private plugin store or a replacement for the official marketplace.

How is this different from the official Omarchy marketplace?

The official marketplace is the listing and installation authority. This catalog adds Intent Solutions source links, previews, manifest checks, and a public delivery ledger around those listings.

How do I start?

Open the catalog, choose a plugin, inspect its repository and marketplace record, then use the published install command. Maintainers can start from the shared widget template or volunteer through the maintainer issue form.

What does it cost?

Commercial pricing and contract terms are not established on this site. Each plugin page and its official marketplace record are the authority for current availability.

How does this relate to Intent Solutions?

Intent Solutions builds and operates this catalog as part of its public network of inspectable AI and software systems. Related properties publish demos, practitioner education, and portable agent skills.

Where can I inspect the evidence?

Every catalog entry links to its public source and official marketplace record. The home page also publishes current catalog totals, manifest alignment, preview status, and a delivery ledger.
